# Morse

**Say it in a flash!**

You don’t have to say it! Morse says it in code.

A free, browser-based novelty Morse beacon. Type a short phrase (up to 40 characters) and Morse flashes it with animated eyes. Choose shapes, colors, and mouth styles. Optional letter display, presets, and an away-from-desk loop mode.

## Features
- Flashing eyes in six shapes (vertical pill default)
- Five mouth styles (smile default)
- Custom color or hex
- Optional floating letter display
- Idle loop + one-shot custom phrases
- Works as a persistent display / screensaver-style page
- Add to Home Screen for instant launch (no app store)

## Usage
Open `index.html` in any modern browser, or host it (GitHub Pages works once the repo is public).
